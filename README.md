# Dr. Mintesnot Gizaw Terefe — Waste-to-Energy & Bioenergy Portfolio

A responsive, investor-facing GitHub Pages portfolio designed for African waste-to-energy, biomass and biogas project-development opportunities.

## Package contents

- `index.html` — main investor portfolio
- `capability-statement.html` — print-ready one-page capability profile
- `404.html` — custom error page
- `assets/css/` — responsive styling and print styling
- `assets/js/main.js` — mobile navigation, reveal effects, image lightbox and email-enquiry generator
- `assets/images/` — enhanced and web-optimised field photographs, privacy-conscious permission-letter excerpt, brand mark and app icons
- `manifest.webmanifest` and `.nojekyll` — GitHub Pages/mobile support

No framework, build process, database or paid service is required.

## Publish on GitHub Pages

1. Sign in to GitHub and create a **public** repository named `dr-mintesnot-waste-to-energy`.
2. Open the repository and choose **Add file → Upload files**.
3. Upload **the contents inside this folder**, not the outer folder itself. `index.html` must appear in the repository root.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Choose branch **main** and folder **/(root)**, then click **Save**.
8. Wait a few minutes and open the Pages URL shown by GitHub.
